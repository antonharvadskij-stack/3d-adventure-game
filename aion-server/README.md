# AION Persistent Universe Server

Настоящее серверное ядро AION. Каноническое состояние хранится в PostgreSQL, а не в браузере. Файл state.json и локальные симуляторы не являются источником истины.

Запуск:
`pip install -r requirements.txt`
`uvicorn main:app --host 0.0.0.0 --port 8000`

API:
- GET /health
- GET /world — получить канонический мир; перед ответом учитывается прошедшее время.
- POST /world/tick?seconds=60 — принудительный шаг симуляции.

Серверный цикл делает шаг каждые 30 секунд. Если процесс был остановлен, следующий GET /world учитывает всё время простоя.
